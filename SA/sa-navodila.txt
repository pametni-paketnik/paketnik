Navodila za uporabo iz `ORV`:

- Testi so v `ORV/tests/`.

Zagon testov:

```powershell
cd ..\ORV
python -m unittest tests.test_pripravi_sliko_za_api
python -m unittest tests.test_predobdelaj_podatke
```

Zagon predobdelave v Dockerju:

```powershell
cd ..\ORV
docker compose --profile tools run --rm predobdelava
```
